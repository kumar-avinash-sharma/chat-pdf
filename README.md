# 🚀 Chat-with-PDF AI App

A full-stack AI application that allows users to upload PDFs and ask questions using natural language.

---

## 🧠 Features
- Upload PDF and extract text
- Ask questions from documents
- Context-aware AI responses
- Background processing using BullMQ

---

## ⚙️ Tech Stack
- React (Frontend)
- Express.js (Backend)
- LangChain (AI pipeline)
- BullMQ + Redis (Queue system)
- Docker (Containerization)

---

## 📦 Installation

```bash
git clone https://github.com/kumar-avinash-sharma/chat-with-pdf.git
npm install
```

---

## ▶️ Run Locally

```bash
npm run dev
```
